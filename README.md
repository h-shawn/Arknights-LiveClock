# LiveFace 动态表盘

把视频循环播放成“表盘”的 Apple Watch App：全屏动画，上面叠一层自己画的时间。也可以放会走动、能互动的桌宠：轻点戳她，按住拎起来甩出去，在空白处拖动逗她追手指，歪手腕她会往低处滑，甩手腕把她颠起来，长按空白处换背景，转表冠换角色。

watchOS 不开放第三方表盘，所以它其实是个 App。配合手表的「返回时钟」设置，抬腕时看到的一直是它。

## 功能

- 三种背景，按 `LiveFace/Frames/` 里放了什么自动选择：
  - 桌宠：`pets/` 里每位角色一个文件夹（`pet.json` 加精灵帧），背景图放在 `backgrounds/`（按文件名前面的序号排，`1-` 后面是名字；一张都没有时用纯深色）。现在带的是史尔特尔、假日威龙陈、玛恩纳三位，八张宿舍背景按人分组：1–2 配史尔特尔（火山、城堡），3–5 配假日威龙陈（海边、港都、庙会），6–8 配玛恩纳（喀兰贸易、谢拉格、雪山）。角色会自己待机、走动、偶尔坐到凳子上，夜里（默认 23 点到 7 点）走到垫子上躺下睡觉。可以这样跟她玩：
    - **轻点**：做一次互动动作
    - **按住她，或从她身上直接拖**：拎起来（手表轻震一下），跟着手指像钟摆一样晃；松手就掉下去，甩得猛会弹一下、摔晕冒星星，丢到凳子上会坐下
    - **在空白处拖动手指**：她会跑过来追，追上了开心一下
    - **歪手腕**：歪得厉害（约 27° 以上）她会往低的一边滑，猛地一歪会撞到屏幕边晕一会儿；坐着的歪得更狠会从凳子上滑下来。拎着、在空中时也会偏向低的一边
    - **甩一下手腕**：把她颠起来，甩得越猛飞得越高，撞到屏幕顶会晕；她还在空中时再甩，能接着颠
    - **在空白处按住不动**：换背景
    - **在空白处连点两下**：打开设置（时间样式、12/24 小时制、常亮亮度、几点睡觉、手腕灵敏度），改完点「完成」
    - **转表冠**：换角色。背景和角色的选择都会被记住

    夜里被弄醒后，她会醒 20 秒左右再接着睡
  - 视频：有 `frame-*.jpg` 时，全屏循环播放
  - 都没有时，播内置的水波动画
- 五种时间样式，设置里能选其中四种（出厂默认「顶部」）；「菜单」是给视频模式做的，不列在设置里，要用改 `Prefs.clockStyle` 的出厂值：
  - 经典：左下角日期 + 大号时间
  - 菜单：仿 P3R 主菜单，右侧四行斜体
  - 居中：细体大字
  - 顶部：时间和日期在上方，下半屏留给角色（配桌宠用）
  - 纯动画：不画时间，只留右上角系统自带的小时间（其他样式会把系统时间藏掉，避免出现两个时间）
- 放下手腕（常亮显示）时背景变暗、时间照常每分钟更新；角色不再定格在走一半或者半空中，而是画成站稳（本来在坐、在睡就保持坐、睡）的样子
- 按屏幕宽高自动缩放，各种尺寸的 Apple Watch 都能用
- 帧数据用内存映射读，不一次性读进内存；播到哪一帧才解码哪一帧，刚解过的三帧留着复用
- 桌宠精灵帧压成 256 色的 PNG（体积只有三成），待机、坐、睡的动作用 15 fps，走路和互动用 30 fps

## 需要准备

- Mac + Xcode。Xcode 版本要支持你手表上的 watchOS：watchOS 26 用 Xcode 26，watchOS 27 用 Xcode 27。第一次连手表时，Xcode 会提示下载 watchOS 平台组件（几个 GB）。
- 和手表配对的 iPhone，一根数据线
- Apple ID。免费账号就行，但签名 7 天后过期，过期后重新运行一次即可

## 1. 换成你的视频（可选）

```sh
cd ~/Code/LiveFace
swift scripts/make_frames.swift ~/Downloads/你的视频.mp4 --start 3 --duration 6
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--start` | 0 | 从第几秒开始截 |
| `--duration` | 6 | 截多长（秒）。帧数 = 时长 × 帧率 |
| `--fps` | 12 | 帧率 |
| `--x` | 0.5 | 横屏视频取景框的水平位置：0 最左，1 最右 |
| `--y` | 0.5 | 竖屏视频取景框的垂直位置：0 最上，1 最下 |
| `--crossfade` | 0 | 首尾交叉淡化的秒数。片段首尾接不上时设 0.5–1，循环就不会跳 |
| `--size` | 422x514 | 输出像素。默认值对所有尺寸的手表都够用 |
| `--quality` | 0.8 | JPEG 质量 |
| `--out` | LiveFace/Frames | 输出目录 |

帧会写进 `LiveFace/Frames/`，旧帧和桌宠素材会先清掉。重新运行到手表就生效。想换回水波动画，删掉 `LiveFace/Frames/` 里除 README 以外的文件即可。

5–8 秒、首尾画面差不多的片段效果最好。6 秒、12 fps 是 72 帧，两三 MB。

## 2. 装到手表

1. `open LiveFace.xcodeproj`
2. 在左侧点工程 → TARGETS 选 **LiveFace** → **Signing & Capabilities**：
   - **Team** 选你的 Apple ID（Personal Team）。
   - **Bundle Identifier** 如果提示已被占用，改成独一无二的，比如 `com.你的名字.liveface`。
   - TARGETS 里的 **LiveFaceWidget**（表盘上的复杂功能）也选同一个 Team；它的 Bundle Identifier 要是 App 的加上 `.widget`，比如 `com.你的名字.liveface.widget`。
3. iPhone 和手表都打开开发者模式：设置 → 隐私与安全性 → 开发者模式。手表上的这个开关，要等 Xcode 发现过手表一次之后才会出现。
4. 在 Xcode 顶部的运行目标里选你的手表，按 ⌘R。第一次要拷贝调试符号，可能要十几分钟，期间让手表保持亮屏、解锁。
5. 如果提示“不受信任的开发者”：在 iPhone 上打开设置 → 通用 → VPN 与设备管理，信任你的证书，再运行一次。
6. 装好后在 Xcode 里点停止，然后在手表上直接打开「LiveFace」。

连不上手表？先关掉 Mac 上的代理或 VPN，让 Mac、iPhone、手表连同一个 Wi-Fi，并让手表的蓝牙保持开启。

没有手表也可以先用模拟器看效果：在 Xcode → Settings → Platforms 里下载 watchOS 模拟器，运行目标选一个手表模拟器。

## 3. 让它一直留在屏幕上

在手表上打开：设置 → 通用 → 返回时钟 → LiveFace → 自定 → 1 小时后。也可以在 iPhone「Watch」App → 通用 → 返回时钟 里设置。

这样放下手腕后一小时内再抬腕，看到的还是它。超过一小时没看会回到系统表盘，重新打开一次即可。

## 4. 在系统表盘上放一个快捷入口

App 里带了一个复杂功能，放在长条位置时显示三样东西：**当前干员的头像**、**另一座城市的时间**、**今天的运动圆环**。点一下直接打开 LiveFace。圆形和角落位置只放头像，时间当弯曲的小标签显示。

在手表上长按系统表盘 → 编辑 → 往左滑到「复杂功能」→ 点一个位置 → 在列表里找到「LiveFace」。也可以在 iPhone「Watch」App 里编辑表盘。

- **头像**：跟着你在 App 里选的干员变，从基建小人的待机首帧裁出来（`scripts/make_pet_avatars.py` 生成，加干员后跑一次）
- **城市**：在 App 的设置页里选（空白处双击打开），表盘上显示英文名。做法是把时刻按时差整体挪一下再交给系统画，这样每分钟自动走字，不占复杂功能的刷新配额
- **运动圆环**：外红内青依次是活动、锻炼、站立，和系统「体能训练」读的是同一份 `HKActivitySummary`。第一次打开 App 会问一次健康数据权限，不给就只显示头像和时间。圆环**一小时刷一次**，另外每次打开 App 也会刷一次——复杂功能的刷新次数系统有配额，做不到实时

彩色表盘（颜色选「多色」）上头像是彩色的、圆环是原本的红绿蓝；单色表盘上头像变黑白。这是系统行为：单色表盘只按透明度画图片，所以代码里备了一套「白色 + 透明度=明暗」的黑白头像。圆环是画出来的形状不是图片，两种表盘都正常。

App 和复杂功能靠 App Group `group.com.shawn.liveface` 共享设置（免费账号也能用，Xcode 会自动创建）。

## 自定义

| 想改什么 | 改哪里 |
|---|---|
| 时间样式、12/24 小时制、常亮亮度、几点睡觉、手腕灵敏度、表盘上显示哪座城市的时间 | App 里，空白处连点两下（存在 App Group 的 UserDefaults 里，见 `LiveFace/Settings.swift`） |
| 这几项的出厂默认值 | `LiveFace/Settings.swift` 里的 `Prefs` |
| 桌宠站的高度、走动范围、凳子位置 | `LiveFace/FaceConfig.swift` |
| 桌宠多久走一次、坐多久、待机多久 | `LiveFace/Pet.swift` 里的 `PetBrain` |
| 歪多少会滑、甩多猛算甩一下 | 先在设置里调「手腕灵敏度」；基准值在 `LiveFace/Pet.swift` 的 `Physics` 和 `LiveFace/WristMotion.swift` 的 `shakeThreshold` |
| 表盘复杂功能的版式 | `LiveFaceWidget/LiveFaceWidget.swift` |
| 复杂功能里的干员头像 | `python3 scripts/make_pet_avatars.py`（加了干员就跑一次）。想在自己表上换成别的图：把图放进 `LiveFace/Frames/pets/<干员>/avatar-source.png` 再跑一次，会额外生成优先使用的 `avatar-local-*`，这两样都在 `.gitignore` 里不会入库 |
| 可选的城市列表 | `LiveFace/Settings.swift` 里的 `Prefs.cities`，加一行要同时在 `LiveFaceWidget/LiveFaceWidget.swift` 的 `PetAvatars.names` 里加英文名 |
| 桌宠精灵帧的体积 | `sh scripts/compress_frames.sh` 把帧压成 256 色（需要 `brew install pngquant`），体积降到三成，手表上解码一样快 |
| 时间的字号、位置、颜色；加新样式 | `LiveFace/ClockStyles.swift` |
| 没放视频时的默认动画 | `LiveFace/Background.swift` 里的 `WaveBackground` |

菜单样式是给右侧偏暗的画面设计的。换了视频后如果文字压到画面主体，就调整 `MenuClock` 里的 `top`、`right` 和字号。

## 已知限制

- 它是 App 不是表盘：太久不看会退回系统表盘，可以点系统表盘上的复杂功能再打开。
- 模拟器没有运动传感器，歪手腕、甩手腕只能在真手表上试。
- 右上角的系统时间是用 SwiftUI 没写进文档的 `_statusBarHidden` 藏掉的（公开文档里的 `persistentSystemOverlays`、`toolbar(.hidden)` 等写法在 watchOS 上都无效）。在 watchOS 27 模拟器上验证有效，但以后的系统更新可能让它失效；这种 App 也不适合上架。
- 常亮显示时动画停住，这是 watchOS 对所有 App 的限制。
- 比静态表盘耗电：抬腕亮屏期间一直在解码、绘制画面，还会读运动传感器。
- 表盘上的运动圆环一小时才刷一次，刚运动完不会马上变（复杂功能的刷新配额限制）。
- 手表上的 ImageIO 不支持 WebP；HEIC 虽然支持，但真机上解一帧要 10 ms，是 PNG 的四倍，不适合逐帧播。所以精灵帧还是 PNG，只是压成了 256 色。
- 免费签名 7 天后过期。
